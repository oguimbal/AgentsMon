# Provider icons

The provider marks are pre-rasterized to 16×16 PNGs so AgentsMon does not load
an SVG renderer or oversized bitmap at runtime.

- `openai-16.png`: OpenAI Blossom from the official OpenAI brand asset,
  <https://images.ctfassets.net/kftzwdyauwt9/3hUGLn3ypllZ0oa01qOYVq/28e8188e6f11b84c3e876569d492734f/Blossom_Light.svg>
- `claude-16.png`: Claude symbol sourced from Anthropic via Wikimedia Commons,
  <https://upload.wikimedia.org/wikipedia/commons/b/b0/Claude_AI_symbol.svg>
  (CC0 metadata: <https://commons.wikimedia.org/wiki/File:Claude_AI_symbol.svg>)

Both files preserve the official geometry and are only resized for the micro UI.
